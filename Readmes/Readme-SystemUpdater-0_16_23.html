1. Introduction

This package contains the System Updater for the following development hardware.

  • PARTNER-CTR Debugger
  • PARTNER-CTR Capture Debugger
  • PARTNER-CTR Capture
  • CTR Test Unit

Operation is not guaranteed on any other development hardware.

Contact your Nintendo support representative if you discover any bugs or issues not listed in this document.

2. Notes

  • Version Displayed in System Settings

    The version is not accurately applied to System Settings on the development hardware's HOME Menu; a fixed value of "Ver. 0.0.0-0J" is displayed instead. (The version is accurately applied on retail hardware.）Check the Firmware Ver. field on the Test Menu screen (the menu specifically for development) or on the Dev Menu screen for the correct version number.


  • Updates and Rollbacks with System Updater

    If you have installed version 0.14.23 or later on your development hardware, you can now update by simply applying a single System Updater corresponding to the CTR-SDK version that you want to use. Similarly, you can now roll back by simply applying a single System Updater corresponding to the CTR-SDK version that you want to use.


  • Ensure that the development hardware is plugged in and charging during the update process.

    If it is turned off in the middle of an update, the update will fail and the development hardware may become unusable.
