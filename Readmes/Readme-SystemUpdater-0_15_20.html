1. Introduction

This package contains the System Updater for the following development hardware.

  • PARTNER-CTR Debugger
  • PARTNER-CTR Capture Debugger
  • PARTNER-CTR Capture
  • CTR Test Unit

Operation is not guaranteed on any other development hardware.
Contact your Nintendo support representative if you discover any bugs or issues not listed in this document.

Version 0.15.20 updates the HOME Menu and built-in applications from version 0.15.19. There are no changes to System Updater itself.

2. Notes

  • Main Changes to System Updater

    System Updater includes the following changes, starting from versions 0.14.24 and 0.15.

    - A System Updater has been provided for each region. For this reason, RegionSelector is no longer included in the package, although it was provided in System Updater versions up to 0.14.23.
    You can set the language when running a system update either by using the Config tool or by using the HOME Menu System Settings.
    The versions of the Config tool with which you can configure this setting are versions 0.14.24 and 0.15.1.

    - CIA files that had been included in the HOME Menu package are now included in System Updater.


  • Version Displayed in System Settings

    The version is not accurately applied to System Settings on the development hardware's HOME Menu; a fixed value of "Ver. 0.0.0-0J" is displayed instead. (The version is accurately applied on retail hardware.）
    Check the Firmware Ver. field on the Test Menu screen (the menu specifically for development) or on the Dev Menu screen for the correct version number.


  • Updates and Rollbacks with System Updater

    If you have installed version 0.14.23 or later on your development hardware, you can now update by simply applying a single System Updater corresponding to the CTR-SDK version that you want to use. Similarly, you can now roll back by simply applying a single System Updater corresponding to the CTR-SDK version that you want to use. Note, however, that you cannot roll back past version 0.14.24. Version 0.15 and subsequent versions are backwards-compatible with applications created for versions 0.14.23 and 0.14.24. Version 0.14.24 is also backwards-compatible with applications created for version 0.14.23.


  • File Deletion When Running an Update

    System Updater versions 0.14.23 and later clear the NAND memory before applying the update, so there is no need to manually clear the NAND memory beforehand.
    When updating from version 0.14.23, it is possible to delete CIA files imported from the HOME Menu package. However, the hardware might malfunction if certain CIA files are deleted, so be careful to apply the update without deleting these CIA files.


  • Handling Errors During Finalization

    The following errors may occur when finalizing the update process, but there is no specific action required.
    The system update itself is carried out without problems.

    --------------------
    Level -5
    Summary 8
    Module 64
    Description 3
    --------------------


  • Ensure that the development hardware is plugged in and charging during the update process.
    If it is turned off in the middle of an update, the update will fail and the development hardware may become unusable.
