1. Introduction

This package contains the System Updater, Config tool, and RegionSelector for the following development units.
Run the RegionSelector if you intend to use CTR-SDK version 0.13 or later.
Note: The Config tool included in this package has a different filename from the one in the CTR-SDK, but is otherwise identical.

  • PARTNER-CTR Debugger
  • PARTNER-CTR Capture Debugger
  • PARTNER-CTR Capture
  • Test Units
  • TS Boards (In the future, the operation of TS boards will no longer be guaranteed.）

Running this package on any other development device is not supported. Do not initialize environment settings using the System Updater or Config tool, and do not change the region and language using the Region Selector.
Contact your Nintendo support representative if you discover any bugs or issues not listed in this document.

2. Notes

■ Order in which to apply updates

You can update to version 0.14.1 from any of the minor versions 0.14.0.x.

To update to 0.14.13, you must complete the updates starting with 0.14.1 and ending with 0.14.13 in order.
If you directly upgrade to 0.14.4 from a version older than 0.14.3, even if the update appears to succeed, issues such as important files not being imported may occur.

For versions 0.14.2 through 0.14.13, the update has only one stage. There is no second stage.

■ Notes when updating with SystemUpdater 0.14.5

When SystemUpdater 0.14.5 is run, the error below sometimes occurs at the end of its update (during Finalization).
--------------------
Level -5
Summary 8
Module 64
Description 3
--------------------

When you see this symptom, restart the hardware, perform ResetSetting in the Config tool, and run RegionSelector. After that you can use the system without problems.
As a workaround, you can also run ResetSetting in the Config tool before you update to 0.14.5. If you do so, this error will not occur.
This error is caused by problems in the language settings during SystemUpdater finalization, when SystemUpdater runs ResetSetting.
The system update itself is carried out without problems.

3. Known Bugs

■ Common to All Development Hardware

System Updater 0.14.2 does not import the DevMenu automatically. You must therefore import it manually using the following procedures. This problem has been fixed in version 0.14.3.

● For PARTNER-CTR Debugger, Capture Debugger, and TS Boards

  1. Place DevMenu.cia, included with the CTR-SDK, onto an SD Card.
  2. Run DevMenu.csu from the debugger software.
  3. Using the DevMenu import screen, import DevMenu.cia from the SD Card.

● For Test Units and PARTNER-CTR Capture

  1. Place DevMenu.cia onto an SD Card.
  2. Write DevMenu.csu onto a CTR Flash Card.
  3. At the initial startup screen, run DevMenu from the CTR Flash Card.
  4. Using the DevMenu import screen, import DevMenu.cia from the SD Card.

■ For PARTNER-CTR Debugger and PARTNER-CTR Capture Debugger

  • The text "Current firm version: Unknown" is displayed when System Updater 0.12 or later is run.
    This is a known bug starting from this version. The only issue is that the wrong text is displayed; it causes no problems in operation.


  • System Updater cannot be loaded from the debugger software while a CTR Flash Card is inserted.


■ For PARTNER-CTR Capture and Test Units

  • Because updates sometimes fail when there are applications in NAND memory, we strongly recommend that you delete all applications in NAND memory before running an update. Pay attention to the following precautions on deleting programs from Programs.


  • Precautions for Deleting Programs
    You can safely delete the program indicated by "00001000 CTR-P-CTAP (JPN)" under Programs in DevMenu after version 0.11.X or later of the updater has been installed. Note, however, that if you delete this program when the installed updater version is 0.10.X you will no longer be able to start the system.


  • Method for Cancelling Screens That Are Forced To Be Displayed (CTR-SDK 0.11 or Later)
    If the system detects any unusual processing, it fills the upper and lower screens with red and yellow to notify the user. Simultaneously press L + R + START + SELECT to release the system from this forced screen display.


  • Prevent the Remaining Battery Life from Reaching 0% (CTR-SDK 0.10.2)
    If the remaining battery life reaches 0% with System Updater 0.10.0 through 0.10.2, the system may no longer turn on even if you recharge its battery. Report to your equipment manager if you cannot turn the power back on. (This issue has been improved in version 0.11.)

    The power LED on CTR test units running System Updater 0.10.0 through 0.10.2 behaves as follows in response to the remaining battery life.
    • 10% -100%: Steady blue light
    • 5% -10%: Steady red light
    • 0% - 5%: Unlit
    The final specifications do not use this behavior. Use this as reference to confirm the amount of remaining battery life when using System Updater versions 0.10.*.


  • Ensure that hardware is plugged in and charging during the update process. If it is turned off in the middle of an update, the update will fail and the hardware may become unusable.


  • The First Files Copied to an SD Card Are Not Displayed (CTR-SDK 0.9.7)
    The first files copied to an SD Card may not be displayed onscreen with CTR-SDK 0.9.7 (factory settings). If this happens, first copy some suitable data to the SD Card and then copy over System Updater.


  • The Current Firmware Version Is "Unknown" with System Updater 0.12 or Later
    When you run System Updater 0.12 or later, "Current firm version: Unknown" is displayed. This is a known bug in this version of System Updater.

    The only issue is that the wrong text is displayed; it causes no problems in operation.


■ Other Known Bugs
